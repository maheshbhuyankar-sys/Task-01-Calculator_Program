This project is a console-based Basic Calculator Application developed in the C programming language. It is designed to perform core arithmetic calculations efficiently while providing a clean, user-friendly command-line interface.
​The program takes two numeric inputs from the user and applies a selected arithmetic operator using structured control logic. It operates in a continuous loop, allowing users to perform multiple operations sequentially without needing to restart the application.
​🚀 Key Features
​Core Arithmetic Operations: Supports addition (+), subtraction (-), multiplication (*), and division (/) handling standard floating-point numbers (double) for high precision.
​Efficient Control Flow (switch-case): Uses a robust switch-case block instead of messy if-else chains to determine and execute the selected mathematical operation instantly.
​Runtime Error Handling & Validation: * Prevents application crashes by detecting and handling division-by-zero attempts.
​Validates user inputs and displays clean error messages for invalid operators or non-numeric inputs.
​Interactive Loop System: Features an automated repetition prompt (while loop) allowing the user to decide whether to run another calculation or exit gracefully.
​Polished Output Formatting: Outputs results restricted to two decimal places (%.2lf) to ensure clean, readable, and presentation-ready terminal data.
​🛠️ Technical Stack
​Language: C (C99/C11 Standard)
​Libraries Used: <stdio.h> (Standard Input/Output) and <stdlib.h> (Standard Utility Library)
